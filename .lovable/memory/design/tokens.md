# EVORIA Brand System

## Identity
- Premium fitness-tech / health-tech, luxury startup feel
- NOT generic gym/bodybuilding/supplement aesthetic
- Teal = brand identity. Orange = CTA only. Green = progress only.

## Core palette
- Background: #090B11 (HSL 220 30% 6%)
- Card: #0F121B / Secondary card: #10141D
- Charcoal surface: #1D242B
- Primary (teal): #00C4B3 (HSL 174 100% 38%)
- Steel blue support: #7FA2B6
- Foreground text: #F3F1EC, muted: #8B93A7

## CTA accent (use sparingly)
- Primary CTA: #FF6A00 → token `cta` / class `bg-cta`
- Hover: #FF7F1F

## Progress
- Success green: #B7FF2C → `--success`

## Color ratio
70% dark surfaces / 15% light text / 10% teal accents / 5% orange CTA

## Typography
- Headings: Space Grotesk, tracking -0.015em
- Body: Inter
